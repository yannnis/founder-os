07 / Approvals

What the bots can do. What needs founder approval.

The bots can research, analyze, draft and update internal systems. Publishing, messages, spend and roadmap commitments require founder approval.

Runs automatically

  • ✓Research + monitoring
  • ✓Evidence capture + analysis
  • ✓Briefs + internal recommendations
  • ✓Drafts + repurposing
  • ✓Performance reviews + learning memos
  • ✓Notion cards + shared state updates

Needs founder approval

  • !Publishing
  • !Public comments + replies
  • !Outbound messages
  • !Spend + destructive actions
  • !Permission changes
  • !Roadmap / tracker commitments
